eSpeak NG with MBROLA

This add-on gives NVDA an eSpeak NG synthesizer that drives MBROLA voices. eSpeak NG produces the phonetic timing and pitch, and MBROLA produces the audio from a diphone database. The result keeps eSpeak's responsiveness and navigation behaviour while using a recorded human voice.

Requirements

  • NVDA 2026.1 or later, 64-bit. The add-on loads a 32-bit helper process, so it will not run on older NVDA releases.

Voices included

One voice is installed by default and two are shipped:

  • US English, USD16, 16 kHz. This is the default voice. It works in every NVDA configuration and is the lightest option.
  • US English, USD, 22.05 kHz. The same recordings at a higher sample rate, included as a proof of concept for higher-fidelity databases. It uses more memory and about 40 percent more disk space.

Both voices come from this project's own recordings and are published under CC BY 4.0.

Adding other MBROLA voices

The add-on supports any MBROLA database, not only the one it ships with. Only databases that are actually present are listed in NVDA's voice list, so nothing appears broken when a voice is missing.

To add a voice:

  • Download a database from the MBROLA voices collection at github.com/numediart/MBROLA-voices.
  • Copy the database file into the folder espeak-ng-data\mbrola inside the add-on directory under your NVDA configuration folder.
  • eSpeak already ships the matching voice descriptor and phone translation table for the standard MBROLA voices, so no further configuration is needed.
  • Restart NVDA. The new voice appears in the voice list with the other MBROLA voices.

Each MBROLA database has its own licence and its own author. The standard terms allow free copying and distribution, provided the notice travels with the database, and they forbid selling the database or embedding it in a sold product without the author's permission. They also permit use only with MBROLA itself. Read the license.txt file that comes with each voice before you redistribute it.

Settings

  • Voice: the MBROLA voice to use.
  • Rate: maps to an eSpeak speaking rate. Rate boost multiplies it by 1.5. Fast rates remain intelligible because the timing model keeps vowel and consonant floors instead of letting durations collapse.
  • Pitch: the base pitch of the voice.
  • Inflection: the pitch range eSpeak applies on top of the base pitch.
  • Volume: applies gain through a soft limiter, so raising it does not clip.

Capital pitch change is not supported by the MBROLA path. Use NVDA's "beep for capitals" setting instead.

Troubleshooting

  • No speech after selecting the synthesizer: make sure the chosen voice's database file is present in espeak-ng-data\mbrola.
  • The voice list is empty: no database was found. Add one as described above.
  • Speech starts late on the first utterance: the helper process is starting. Subsequent utterances begin within a few milliseconds.
